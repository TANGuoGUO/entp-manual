# ENTP 自强手册 2.0

一个用 Python、Flet 与 SQLite 编写的本地桌面程序，用来分离主线执行与独立灵感候审，并记录真实执行结果。

## 启动

优先双击 `启动_ENTP自强手册.vbs`，它不会显示命令行黑框。也可以使用 `启动_ENTP自强手册.bat`。

如果界面未出现，请查看 `logs/startup.log` 和 `logs/crash.log`；也可以运行 `检查环境.bat`。

也可以在项目虚拟环境中启动：

```powershell
.venv\Scripts\python.exe flet_app.py
```

程序使用 Flet 构建桌面界面，数据默认保存在同目录的 `entp_manual.db`，每个对象同时对应独立 Markdown 文档。

## Windows 安装版

已提供标准 Windows 初始化安装包：`release/ENTP自强手册_2.0.0_初始化版.exe`。安装时可以选择安装目录、桌面快捷方式，以及“登录 Windows 后在后台启动（隐藏任务栏图标，使用任务计划程序）”。该自动启动项默认不勾选。运行中可以从左下角隐藏到系统托盘，双击托盘图标恢复窗口，通过托盘菜单真正退出。开始菜单同时提供“卸载 ENTP 自强手册”，也可以从 Windows“已安装的应用”中卸载。

应用图标采用紫色低多边形“辩手在讲台输出观点”的原创形象，源自产品的 ENTP 梗；同一图标用于窗口、EXE、安装程序、开始菜单、桌面快捷方式、侧栏和系统托盘。

首次启动空工作区时会生成一套可直接操作的产品导览数据：主线、任务、收集箱、灵感四种状态、今日账本以及今天/昨天的完成日历示例都用于解释对应功能。它们都是普通内容，可以直接修改、完成或归档。初始化只在数据库完全为空时执行，不会在升级或再次启动时重复写入，也不会覆盖用户数据。

安装版把数据库、Markdown、日志和备份保存在 `%LOCALAPPDATA%\ENTP自强手册`，而不是可能没有写入权限的程序安装目录。详细构建与卸载行为见 `WINDOWS_INSTALLER.md`。

## 2.0 核心功能

- 可保存多条主线，但执行区只突出一条“当前主线”；切换不会删除其他主线。
- 左侧采用单层导航，不再同时显示图标栏和重复的文字栏。
- 执行页不暴露其他主线；它们统一进入独立的“我的主线任务保管箱”，只有主动进入保管箱时才能切换。
- 新建主线直接进入空白记录页，不弹表单；只提供标题和自由正文，并自动同步 Markdown。
- 主线可以归档和恢复；归档不删除任务或 Markdown。归档当前主线时会先切换到另一条未归档主线，且最后一条活动主线不能被归档。
- 当前主线下可以建立多个任务，同时只突出一个“当前推进”任务。
- 每个任务可填写“最小下一步”，并逐次记录行动、结果、阻碍和新的下一步。
- 任务完成后自动写入当天的完成日历；恢复任务不会抹除历史完成事实。
- 时间限制和复盘提醒完全可选，默认不设置、不倒计时。
- 汇总所有主线的今日工作清单，并用真实日期形成每日账本。
- 今日清单采用滴答式分组列表，支持回车快速添加、过期结转、完成/恢复、折叠和优先级排序。
- 支持前后日期回看和月历跳转；历史记录保存任务标题与主线快照。
- 完成日历按月展示所有主线的完成分布，点击日期可查看完成任务与真实完成时间，并可进入当天只读账本。
- 统一圆角视觉系统：柔和侧栏选中态、圆角卡片、轻层次和圆角表单控件。
- 响应式桌面布局：1180px 窄窗口自动切换两列看板、上下执行区和重排后的思路工作台；大屏限制阅读行宽。
- 提升正文、导航和卡片字号，不通过缩小字体解决空间不足。
- 完成、重新打开、结转均写入事件记录，日期更迭不会篡改旧记录。
- 候审区是独立灵感池，灵感默认不关联主线。
- 执行中出现的新灵感在当前页用一行输入框快速收纳，回车即保存并收起，不再弹出预设表单。
- 候审看板只展示“未审视 / 待孵化 / 正在尝试”；每张卡片可单独展开，也可用小图标一键孵化、尝试或归档，不使用状态下拉框。
- “已归档”是独立的灵感回收站，不参与日常候审；其中内容仍保留 Markdown，并可一键恢复到“未审视”。
- 展开后只有标题、状态、自由标签和一张空白 Markdown 记录页，不预设类别或思考问题。
- 没动力时可以自由审视不同领域的灵感，而不是只召回当前主线内容。
- 思路与任务关联；思路与思路可建立支撑、拆解、启发、冲突、延伸关系。
- 从思路一键生成执行任务。
- 为每条思路持续记录行动、结果、阻碍、下一步和进度。
- 每个主线、任务、思路、单次执行记录和每日账本自动对应一个独立 Markdown 文档；任务文档同步当前焦点、最小下一步和执行历史。
- 内置 Markdown 源码编辑、实时预览和 `Ctrl+S` 保存。
- 支持用 MarkText 或系统默认 Markdown 编辑器外部打开。
- 在“我的主线任务保管箱”中一键导出或导入完整工作空间备份。
- 所有可见交互统一经过异常边界：同步/异步回调失败只终止本次动作，未提交 SQL 自动回滚，导航状态恢复，并记录错误后继续使用当前窗口。

## 文件

- `app.py`：桌面 UI 与交互。
- `database.py`：SQLite 数据结构和读写逻辑。
- `PRODUCT_DESIGN.md`：完整产品功能设计。
- `designs/`：基于参考截图绘制的 UI 概念稿。
- `markdown/`：程序自动维护的 Markdown 文档库与分类索引。
- `vendor/`：项目内置的开源 Markdown 渲染组件，可离线使用。

## Markdown 文档规则

文档目录分为 `主线/`、`任务/`、`思路/`、`执行记录/`、`每日/`。对象文件使用稳定编号，例如 `T0001.md`；每日账本使用 `YYYY-MM-DD.md`。即使任务后来改名，历史账本仍保留当天快照。

每个文件包含两个区域：

- `ENTP-SYSTEM` 标记之间是程序同步区，会根据 SQLite 中的标题、状态、结构化字段和关联自动更新。
- 标记之后是自由记录区，可在程序内或任意外部 Markdown 编辑器中修改，程序同步不会覆盖。

程序优先检测开源的 [MarkText](https://github.com/marktext/marktext)；没有安装时，会交给系统的 `.md` 默认程序打开。

## 数据备份

进入“我的主线任务保管箱”，点击“导出全部”，即可生成一个 `.entp.zip` 完整备份包。备份包含：

- SQLite 中的主线、任务、今日账本、完成事件、灵感关系、执行记录与设置；
- `markdown/` 下的全部自由笔记；
- 用于导入前校验的格式版本、数量、文件大小与 SHA-256 清单。

点击“导入备份”后，程序会先校验整个备份包并展示内容数量。确认导入时，它会先把当前工作空间自动保存到 `backups/`，再整体恢复所选备份。导入采用“整体替换”而非“合并”，避免重复任务、错误关系和完成历史错位。

仍可在退出程序后手动复制 `entp_manual.db`，但这不会包含全部 Markdown；日常迁移和恢复建议使用界面中的完整备份功能。
